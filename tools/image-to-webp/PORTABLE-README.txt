Konwerter obrazów → WebP (wersja portable)
==========================================

Uruchomienie:
  macOS:   Kliknij dwukrotnie "Konwerter-WebP" lub uruchom z Terminala
  Windows: Kliknij dwukrotnie "Konwerter-WebP.exe"

Nie wymaga instalacji Pythona – wszystko jest w tym folderze.
Skopiuj cały folder na pendrive – działa z dowolnej lokalizacji.
