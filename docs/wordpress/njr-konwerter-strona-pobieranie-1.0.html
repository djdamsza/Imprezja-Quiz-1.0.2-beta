NJR Konwerter 1.0

Konwerter i edytor bazy VirtualDJ oraz eksporty (Serato, Rekordbox, DJXML i inne). Obecnie w całości darmowy do testów.

Pobierz dla Windows (.exe) Windows 10 / 11, 64-bit
Pobierz dla macOS — Apple Silicon (.dmg) Mac z chipem M1 / M2 / M3 / M4
Pobierz dla macOS — Intel (.dmg) Mac z procesorem Intel

Mac — instalacja i pierwsze uruchomienie

Program nie jest z App Store — nie potrzebujesz konta Apple Developer. Przy pierwszym uruchomieniu macOS może odmówić startu i pokazać ostrzeżenie — to standardowe zachowanie dla aplikacji pobranych z internetu.

1. Wgraj program do Aplikacje

Otwórz pobrany plik .dmg. W oknie obrazu często jest tylko plik NJR-konwerter (bez skrótu do Aplikacji) — to w porządku.

  • Naciśnij Shift + Command + A, żeby otworzyć folder Aplikacje, i przeciągnij tam NJR-konwerter z okna DMG.
    Lub: zaznacz plik w DMG → Command + C → w Aplikacjach → Command + V.

Potem wysuń DMG (ikona dysku na pulpicie lub w Finderze → wysuń).

2. Zezwól na uruchomienie — Ustawienia systemowe

To jest główny sposób, który działa, gdy macOS blokuje program (np. komunikat z przyciskami „Kosz” i „Gotowe”):

  1. Raz spróbuj uruchomić NJR-konwerter z folderu Aplikacje (np. dwuklik). Gdy pojawi się blokada, zamknij okno (Gotowe).
  2. Otwórz Ustawienia systemowe (ikona koła zębatego w Docku lub menu Apple).
  3. Wejdź w Prywatność i bezpieczeństwo (lub sekcję Bezpieczeństwo, zależnie od wersji macOS).
  4. Przewiń w dół. Powinna być informacja, że NJR-konwerter został zablokowany — obok znajdziesz przycisk w stylu Otwórz mimo to / Otwórz i tak. Kliknij go i potwierdź.
  5. Uruchom ponownie NJR-konwerter z Aplikacje. Kolejne uruchomienia zwykle już nie wymagają tych kroków.

Jeśli przycisku nie widać, upewnij się, że najpierw była próba otwarcia programu — dopiero wtedy macOS dopisuje wpis w ustawieniach bezpieczeństwa.

Kopia zapasowa bazy

Zalecam pracę na kopii zapasowej bazy VirtualDJ i powiązanych plików. Przed większymi zmianami lub eksportami zrób backup, żeby nie uszkodzić oryginalnych danych.

Windows — instalacja

Uruchom pobrany plik .exe i postępuj według kreatora. Gdy pojawi się SmartScreen, wybierz Więcej informacji → Uruchom mimo to.

Jeśli Windows Defender lub inny antywirus zatrzyma instalator, pozwól na uruchomienie albo dodaj wyjątek — pobieraj wyłącznie z tej strony lub z oficjalnego release na GitHubie.
