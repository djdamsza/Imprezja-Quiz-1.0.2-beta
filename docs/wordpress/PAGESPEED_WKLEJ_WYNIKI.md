# PageSpeed Insights – wklej wyniki

Nie mogę pobrać wyników automatycznie (limit API). **Wklej tutaj** lub w czacie – przeanalizuję.

---

## Co skopiować

1. Otwórz: https://pagespeed.web.dev/
2. Wpisz: **imprezja.pl**
3. Kliknij **Analizuj**
4. Skopiuj i wklej:

### Mobile (telefon)
- **Performance** (Wydajność): ___ / 100
- **Accessibility** (Dostępność): ___ / 100
- **Best Practices** (Najlepsze praktyki): ___ / 100
- **SEO**: ___ / 100

### Desktop
- **Performance**: ___ / 100
- **Accessibility**: ___ / 100
- **Best Practices**: ___ / 100
- **SEO**: ___ / 100

### Diagnostyka (jeśli są)
- LCP (Largest Contentful Paint): ___
- FID / INP: ___
- CLS (Cumulative Layout Shift): ___
- Sugestie („Reduce unused JavaScript”, „Properly size images” itd.)

---

## Alternatywa: zrzut ekranu

Możesz też wkleić **zrzut ekranu** wyników – odczytam liczby i sugestie.
